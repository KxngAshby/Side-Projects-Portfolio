## What shipped

Invite-only salary-cap franchise fantasy with **shared cloud leagues**:

- Email sign-in (6-digit code)
- Create / join leagues from a multi-league hub
- One invite = one live room across devices (Cloudflare D1)
- ESPN Half-PPR scoring against the real NFL slate
- $1000 cap, public FA offers, contracts in games, IR, playoffs
